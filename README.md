O ColemenaApoio é um aplicativo Android que conecta estudantes a voluntários para apoio educacional. Ao abrir, o usuário vê a Splash Screen, faz login e acessa a Home, onde pode visualizar, adicionar, editar ou excluir tarefas educativas. Há também uma busca para localizar informações rapidamente.

O sistema foi desenvolvido em Kotlin com Jetpack Compose, usando Room para armazenar dados localmente e API REST para sincronização com o servidor. Ele oferece uma solução prática e organizada para facilitar o acompanhamento pedagógico de estudantes e o trabalho de voluntários.

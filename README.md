O ColemenaApoio é um aplicativo Android desenvolvido em Kotlin com Jetpack Compose, que conecta estudantes a voluntários para apoio educacional. O sistema permite:

Cadastro e autenticação de usuários;

Visualização, adição, edição e exclusão de tarefas educativas;

Busca de tarefas ou voluntários por título, descrição ou data;

Persistência de dados local com Room Database e sincronização remota com API REST.

O objetivo é fornecer uma solução prática e organizada para melhorar o acompanhamento pedagógico de estudantes e facilitar o trabalho de voluntários.
